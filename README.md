# Password Manager

[![License: Unlicense](https://img.shields.io/badge/license-Unlicense-blue.svg)](http://unlicense.org/)

## Описание

Учебный проект по основам Go. CLI-приложение для хранения паролей. Пароли хранятся в файле, зашифрованном с помощью AES-256 алгоритма.

## Установка и запуск

```bash
go run ./main.go
```

## Примеры использования

```bash
=== Password Manager Initialization ===
Enter master password: 
Password manager initialized successfully
Press Enter to continue...

==========================================
           Password Manager
==========================================
1. Generate new password
2. Add new password
3. Get password
4. List all passwords
5. Update password

==========================================
```
